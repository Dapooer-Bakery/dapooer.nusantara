\f0\fs24 \cf0 # Dapooer Nusantara\
\
A single-page bakery management dashboard for tracking daily inventory, transfers,\
supplier orders, booth performance, sales, and costs.\
\
## Features\
\
- **Dashboard** \'97 Today's sales, costs, active booths, low-stock alerts\
- **Daily Inventory** \'97 Enter MASUK / SISA / WASTE per product with freshness levels\
- **Inventory History** \'97 View any booth/date combination\
- **Transfers** \'97 Move stock between booths with freshness tracking\
- **Products** \'97 Manage product codes, cost, sell price, freshness rules\
- **Booths** \'97 Booth contracts, hours, sales targets\
- **Suppliers** \'97 Supplier records with product assignments\
- **Purchase Orders** \'97 Order from suppliers, allocate to booths, mark received\
- **Calendar** \'97 Booth contract scheduling\
- **Reports** \'97 Sales and cost reports by date range and booth\
\
## Data Storage\
\
All data is stored locally in the browser using localStorage. Nothing is sent to a\
server. Use the Export JSON and Backup buttons regularly to save your data externally.\
\
Warning: Clearing browser data will erase your records. Always keep backups.\
